The concept

Three products that look alike but finish work differently.

Chat finishes when it has given you an answer, inside one turn, whether or not the job is done. Cowork works toward a goal: it builds a checklist, works through it (sometimes with sub-agents), and stops only when the goal is met, which might take 2 minutes or 40. The speaker's picture is a vending machine versus a kitchen.

Two more differences follow. Cowork gets a workspace it keeps building on for the whole job, instead of picking up a tool once and putting it away. And it can run on a schedule while you're away, so a Monday briefing can be waiting before you sit down.

The practical smell test: if you find yourself copying Chat's output into a doc or stitching pieces together, that is assembly work you should have delegated. If your problem is "I wish a tool existed for this," that is a job for Code.

What you could do with it

Both options stay general because they depend on your own habits.

New skill

A "which surface should this task go to" check

Package the three tests (does it finish in one turn, does it need a persistent workspace, should it run unattended) plus the copy-paste-assembly smell test into a skill that reads a task description and recommends Chat, Cowork or Code, with the reason. Only worth it if you often misroute work.

Implementation plan

Make a cloud-readable home base and a first scheduled task

The Drive-folder workaround only helps if your working files already live where a connector can reach. Pick one recurring job (the video's example is a weekly briefing), put its inputs in that folder, and set it up as a scheduled Cowork task so it runs without a device online. If your notes already sync to a cloud drive, the first step may be nearly done; check which folder the connector can actually see.

Ready-to-use prompt

Paste into a fresh Claude conversation or Claude Code. It does not assume you watched the video.

Prompt
You are helping me decide which Claude product to use for my recurring work, and then set one up. Background: Claude has three modes. Chat is a thinking partner that finishes after one answer. Cowork takes a goal, builds a checklist, works through it with its own workspace (my local folder on desktop, or a cloud sandbox on web and mobile) until the goal is met, and can run on a schedule while I'm away. Code is the same agent with a code repository loaded, used to build apps, scripts and tools. A sign I'm in the wrong mode is when I copy Chat's output into a document or stitch pieces together by hand.

Do this with me step by step:
1. Ask me to list 5-10 tasks I did in the last two weeks. For each one, classify it as think (Chat), delegate (Cowork) or build (Code), and tell me which of the three tests it passed: finishes in one turn, needs a persistent workspace, or could run unattended.
2. Point out any task where I was doing copy-paste assembly by hand, and say how I would hand it off instead.
3. Pick the one recurring task with the most value as a scheduled Cowork job. Ask what inputs it needs and where they live. If they are only on my local machine, suggest moving them to a cloud folder that a connector can read, so the job can run with my computer off.
4. Write the exact goal statement I would give Cowork, the schedule, and what the finished deliverable should look like, so I can paste it in.

Don't assume which plan I'm on or which features are available to me; ask me to check in the app.
